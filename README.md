# kvp-projects.com

Сайт-каталог моих программ: Mac-приложения, расширения Chrome, дальше Windows, Android, iOS. Русский (`/`) и английский (`/en/`).

- `products.json` — список продуктов: описание на двух языках, значок, журнал изменений, платформы.
- `build.py` — собирает страницы в `docs/` (их и показывает GitHub Pages). Запускать после выпуска или правки списка.
- `assets/` — оформление и значок сайта.
