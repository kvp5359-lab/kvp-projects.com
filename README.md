# kvp-projects.com

Сайт-каталог моих программ: Mac-приложения, расширения Chrome, дальше Windows, Android, iOS. Русский (`/`) и английский (`/en/`).

- `products.json` — список продуктов: описание на двух языках, значок, журнал изменений, платформы, языки интерфейса,
  схема ссылок приложения и где в нём раздел «Лицензия».
- `build.py` — собирает страницы в `docs/` (их и показывает GitHub Pages), а ещё `sitemap.xml` и `robots.txt`.
  Запускать после выпуска или правки списка.
- Страницы кроме каталога: `/activate/` — активация лицензии по ссылке из письма (`assets/activate.js`),
  `/privacy/` — что приложения отправляют в интернет.
- `assets/` — оформление, шрифты, значок сайта, скрипт страницы активации.

Подробно — `.claude/rules/infrastructure.md`.
