Steady Speed

Скорость видео, которая не слетает

Chrome

Скорость видео на любом сайте: не сбрасывается после паузы и перемотки, запоминается для каждого сайта.

Скоро в Chrome Web StoreGoogle Chrome и браузеры на его основе
  • Скорость держится после паузы, перемотки и полноэкранного режима
  • Запоминание по сайту, по вкладке или везде
  • Закладки на видео с названиями из субтитров
  • Горячие клавиши при любой раскладке

Бесплатно. Тексты, записи и файлы остаются у тебя.

Что нового

Версия 0.1.0 · 2026-10-11

Добавлено

  • Управление скоростью видео на любом сайте; скорость не сбрасывается после паузы, перемотки, полноэкранного режима и «картинки в картинке».
  • Скорость запоминается по сайту, по вкладке или везде — выбирается в настройках.
  • Панель на видео с кнопками скорости; её можно перетащить, двойной щелчок возвращает на место.
  • Закладки на видео: отметить момент и вернуться к нему, название подставляется из субтитров.
  • Горячие клавиши работают при любой раскладке и не мешают, пока печатаешь.
  • На сайтах, где расширение выключено, оно вообще не загружается.
  • Интерфейс на английском, испанском и русском; язык выбирается по языку браузера.
