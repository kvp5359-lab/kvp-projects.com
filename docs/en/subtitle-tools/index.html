Subtitle Tools

Dual subtitles for YouTube

The original and a translation at once — on pause or always. Select, copy and save subtitles to a file.

Coming soon to Chrome Web Store

Features

  • Each language has its own mode: off, on pause or always
  • Translation from the author's subtitles, YouTube auto-translate or Chrome's translator
  • The spoken word is highlighted
  • Save subtitles as .txt and .srt
  • Interface in English, Russian and Spanish

The change history is available in Russian.
