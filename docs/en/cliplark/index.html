Earlier versions

Version 0.3.0 · October 11, 2026

Added

  • Updates on their own: once a day Cliplark looks for a new version and shows what's new in it, but installs it only when you agree. To check by hand — Cliplark menu → “Check for Updates…” or Settings → About; the automatic check can be turned off there too. The App Store version keeps updating through the App Store.
  • The app keeps a log of its work, which makes it easier to find out what went wrong. What you copy — texts, images, file names, addresses — never goes into it.
  • Error reports, only with your consent: if something breaks, the developer gets a technical report (Mac model, versions, app state, the work log). What you copied is never part of it. Turn them on in Settings → General.
  • What's New: after an update Cliplark shows once what has changed. The whole list of changes is in the Cliplark menu → “What’s New…” and in Settings → About.
  • Clipboard history: everything you copy — texts, links, images, files, colors — is kept on this Mac.
  • A panel at the bottom of the screen on ⇧⌘V: cards with previews, search, paste with Return (⌥Return — without formatting), ⌘1…9 for quick paste, Space to preview.
  • Lists: keep what you need forever, drag cards into lists and into other apps, create and edit your own texts.
  • Paste Stack (⌥⇧⌘C): copy several items, and each ⌘V pastes the next one.
  • Select several cards (⌘ and ⇧ with a click, ⌘A): paste and drag them all at once.
  • Privacy: passwords from password managers are not saved, excluded apps, pause recording, hide while the screen is shared, history kept out of Time Machine.
  • History limits by age, number of items and disk space.
  • Previews of files copied in Finder and CleanShot — for folders you gave access to (Settings → File Previews).
  • A quiet sound when you copy — choose it in Settings → General.

Changed

  • A new icon — a lark in flight on green. Shotlark has the same lark, in a capture frame.
  • Hints and texts in Russian now speak to you informally, like my other apps.
  • Settings in a new look, like my other apps: soft cards, pill buttons, the icon and version above the sections, the window title is the section name. Search finds single settings, and switches can be flipped right in the results.
  • Settings → About: a button to show the work log in Finder.

  • While a Cliplark window is open (Settings, the tour, the text editor), the app has a Dock icon and a place in ⌘Tab, so the window is easy to find. When the last window closes, the icon goes away and the keyboard returns to the app you were working in.
  • Messages at the bottom of the screen have a colored icon: green for confirmations, orange for errors; a long hint wraps onto several lines.

How to uninstall

In the app: Cliplark menu → «Uninstall Cliplark…» (or Settings → About). Removes the clipboard history, settings and the login item. macOS doesn’t let Cliplark remove itself, so at the end Finder opens — just drag Cliplark to the Trash. Only a small shared folder, kvp-projects/licensing, stays: it remembers since when you’ve been with us and keeps your key, if you have one — for all my apps at once. None of your texts or files are in it.

Planning to come back? Tick «Keep my data and settings» — install Cliplark again and everything will be there.

This is in versions newer than 0.4.0.

By hand (for older versions)

Open Terminal, paste the line and press Return. It quits Cliplark and deletes it along with its data. The line is for zsh/bash (the standard Terminal). The app goes to the Trash via Finder — macOS asks once whether Terminal may control Finder, and also whether it may access other apps’ data (Cliplark keeps everything in its own container).

osascript -e 'if application "Cliplark" is running then tell application "Cliplark" to quit'; sleep 2; osascript -e 'tell application "Finder" to delete POSIX file "/Applications/Cliplark.app"' >/dev/null 2>&1 || echo "Drag Cliplark to the Trash yourself"; rm -rf ~/Library/Containers/app.cliplark.mac ~/Library/Caches/app.cliplark.mac; tccutil reset All app.cliplark.mac
