How to update by hand

Normally an app offers the new version by itself. If it doesn’t, or the update won’t install, put the new version over the old one: your data and license stay where they are.

Where to get the new version

Open your app’s page and press the download button: it’s always the latest version. Dictum, Textum, Cliplark, Shotlark, Note Calc

Don’t uninstall the old version first: the app’s Uninstall button can remove your data too.

On a Mac

  1. Quit the app.
  2. Open the downloaded .dmg file.
  3. Drag the app’s icon to the Applications folder and press “Replace”.

Settings, data and the license are kept apart from the app itself, so they stay. macOS permissions stay too: the new version has the same signature. If the system asks anyway, allow it again.

On Windows

  1. Run the downloaded …-setup.exe file. No administrator rights needed.
  2. If a blue “Windows protected your PC” window appears: press “More info”, check that the file came from this site and its name ends in -setup.exe, then press “Run anyway”. The app has no publisher certificate yet, so Windows warns about it.
  3. The installer closes the app by itself and puts the new version in place of the old one.

Data, settings and the license live in another folder, so they stay. If installing fails, the installer says so and the previous version keeps working.

Browser extensions

Chrome updates them by itself, there’s nothing to download.
