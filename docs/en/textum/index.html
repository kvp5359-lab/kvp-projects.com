Textum Beta

Everything for text, at your cursor

One key opens an action panel at your cursor: AI, smart buttons for the kind of text, snippets, emoji, and fixing text typed in the wrong keyboard layout.

Download for MacVersion 0.3.0 · macOS 15 or later

Beta: the app is in active development, more is on the way.

Features

  • AI actions on selected text: translate, fix, your own commands
  • Smart buttons for links, email, phone numbers, addresses, expressions and currencies
  • Snippets: a keyword expands into text in any app
  • Layout switcher: fixes text typed in the wrong keyboard layout
  • Emoji gallery with search

The change history is available in Russian.
