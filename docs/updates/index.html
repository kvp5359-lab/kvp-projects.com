  3. Note Calc 0.5.012 октября 2026
    • Панель оформления в новом виде, как в Google Документах: кнопки собраны в закруглённые группы, вместо букв — значки. Клик по «A» красит текст последним выбранным цветом (он виден полоской под буквой), стрелка рядом открывает палитру. При прокрутке текст плавно уходит под панель. В узком окне панель не переносится на вторую строку: кнопки, которые не поместились, прячутся под «⋯».
    • Интерфейс без тонких разделительных линий: боковая панель, вкладки, строка итогов, настройки и поля ввода отделены мягкими заливками и скруглениями.
    • Удалить Note Calc с Mac можно из самой программы: меню Note Calc → «Удалить Note Calc…» или Настройки → Справка. Программа уйдёт в Корзину вместе с настройками и лицензией (галочка «Оставить мои данные» их сохранит). Заметки в папке Документы → Note Calc остаются.

  7. Textum 0.3.011 октября 2026
    • Обновления: раз в день Textum проверяет, нет ли новой версии, и показывает её вместе с новостями — ставится одной кнопкой. Пока открыта панель действий, окно не появится. Проверить вручную — меню Textum → «Проверить обновления…»; выключить — Настройки → О программе.

    • Знакомство при первом запуске по шагам: разрешения, ключ Claude (можно обойтись моделью Apple) и горячие клавиши с проверкой. Пройти заново — в Настройках → Общие.
