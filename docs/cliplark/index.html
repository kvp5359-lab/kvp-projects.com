История буфера обмена: тексты, ссылки, картинки, файлы и цвета хранятся на твоём Mac и вставляются по ⇧⌘V.

Скачать для MacВерсия 0.5.0 · macOS 26 или новее · Apple silicon

Бета-версия: приложение активно развивается, возможности ещё добавляются.

Что даёт

Скопированное не теряетсяТексты, ссылки, картинки, файлы и цвета копятся в истории — найди поиском и вставь по ⇧⌘V.
Нужное всегда под рукойСохраняй в списки то, что вставляешь часто, и перетаскивай прямо в другие приложения.
Пароли — мимо историиПароли из менеджеров паролей не сохраняются, а история живёт только на твоём Mac и не попадает в Time Machine.

Что умеет

  • Панель с карточками и превью, поиск, вставка без форматирования
  • Списки: сохраняй нужное навсегда и перетаскивай в другие приложения
  • Paste Stack: скопируй несколько, и каждое ⌘V вставит следующее
  • Пароли из менеджеров паролей не сохраняются, история вне Time Machine
  • Ограничения истории по сроку, количеству и месту

Что нового

Версия 0.5.0 · 29 октября 2026

Добавлено

  • Если открыть Cliplark прямо из образа диска, он предложит перенести себя в «Программы», перезапустится оттуда и отключит образ — иначе разрешения macOS доставались временной копии и не работали.
  • Cliplark можно удалить из самого приложения — вместе с историей или оставив её; само приложение останется перетащить в Корзину (меню Cliplark → «Удалить Cliplark…»).

Исправлено

  • «Проверить обновления…» отвечает понятно: «У тебя последняя версия» — без загадочных номеров сборки.
Предыдущие версии

Версия 0.4.0 · 11 октября 2026

Добавлено

  • Настройки → О программе → «Лицензия»: Cliplark сейчас в бете, всё бесплатно. Там же — поле для лицензионного ключа на будущее и с какого дня ты с нами.

Исправлено

  • Отчёты об ошибках теперь доходят из любой страны, включая Россию: они идут через мой сервер. Включаются и выключаются, как раньше, в настройках.
  • Окно «Что нового» теперь появляется и после первого обновления — раньше, если Cliplark поставили недавно, оно пропускалось.
  • Окно проверки обновлений и вопрос про отчёты об ошибках больше не прячутся за другими окнами — сразу видны впереди.
  • В отчётах об ошибках больше нет имени пользователя Mac — ни в путях к файлам, ни в отчётах о падениях.

Версия 0.3.0 · 11 октября 2026

Добавлено

  • Обновления сами: раз в день Cliplark проверяет новую версию и показывает, что в ней нового, а ставит только с твоего согласия. Проверить вручную — меню Cliplark → «Проверить обновления…» или Настройки → О программе; там же можно выключить автопроверку. Версия из App Store обновляется через App Store, как раньше.
  • Приложение ведёт журнал своей работы: по нему проще понять, что пошло не так. Содержимое копий — тексты, картинки, имена файлов, адреса — туда не записывается никогда.
  • Отчёты об ошибках по согласию: если что-то сломалось, разработчик получит технический отчёт (модель Mac, версии, состояние приложения, журнал работы). Твои копии в отчёт не попадают. Включаются в Настройках → Основные.
  • «Что нового»: после обновления Cliplark один раз показывает, что изменилось. Весь список изменений — в меню Cliplark → «Что нового…» и в Настройках → О программе.
  • История буфера обмена: всё, что ты копируешь, — тексты, ссылки, картинки, файлы, цвета — сохраняется на этом Mac.
  • Панель внизу экрана по ⇧⌘V: карточки с превью, поиск, вставка по Return (⌥Return — без форматирования), ⌘1…9 — быстрая вставка, пробел — просмотр.
  • Списки: сохраняй нужное навсегда, перетаскивай карточки в списки и в другие приложения, создавай и правь свои тексты.
  • Paste Stack (⌥⇧⌘C): скопируй несколько элементов, и каждое ⌘V вставит следующий.
  • Выбор нескольких карточек (⌘ и ⇧ со щелчком, ⌘A): вставка и перетаскивание сразу всех.
  • Приватность: пароли из менеджеров паролей не сохраняются, исключённые приложения, пауза записи, скрытие при показе экрана, история вне Time Machine.
  • Ограничения истории по сроку, количеству и месту на диске.
  • Превью файлов, скопированных в Finder и CleanShot, — для папок, к которым дан доступ (Настройки → Превью файлов).
  • Тихий звук при копировании — выбирается в Настройках → Основные.

Изменено

  • Новый значок — жаворонок в полёте на зелёном. У Shotlark такой же жаворонок, в рамке снимка.
  • Подсказки и тексты — на «ты», как в других моих приложениях.
  • Настройки в новом виде, как в других моих приложениях: мягкие карточки, кнопки-«таблетки», значок и версия над разделами, заголовок окна — название раздела. Поиск находит отдельные настройки, а переключатели можно менять прямо в результатах.
  • Настройки → О программе: кнопка, чтобы показать журнал работы в Finder.
  • Знакомство с приложением стало пошаговым, в том же виде, что и настройки: привет → разрешения → клавиши → готово. Шаги слева, пройденные отмечены галочкой; если закрыть окно, знакомство продолжится с того же шага. Пройти заново — Настройки → О программе → «Приветствие».
  • Пока открыто окно Cliplark (настройки, знакомство, редактор текста), у приложения есть значок в Доке и место в ⌘Tab — окно легко найти. Последнее окно закрыто — значок исчезает, а клавиатура возвращается в программу, где шла работа.
  • Всплывающие сообщения внизу экрана — с цветным значком: зелёным для подтверждений, оранжевым для ошибок; длинная подсказка переносится на несколько строк.

Как удалить

В приложении: меню Cliplark → «Удалить Cliplark…» (или Настройки → О программе). Уберёт историю буфера обмена, настройки и автозапуск. Убрать сам себя macOS ему не даёт, поэтому в конце откроется Finder — просто перетащи Cliplark в Корзину. Остаётся только маленькая общая папка kvp-projects/licensing: она помнит, с какого дня ты с нами, и хранит ключ, если он есть, — для всех моих приложений сразу. Твоих текстов и файлов там нет.

Собираешься вернуться — поставь галочку «Оставить мои данные и настройки»: поставишь Cliplark снова, и всё будет на месте.

Эта кнопка есть с версии 0.5.0.

Вручную (для старых версий)

Открой Терминал, вставь строку и нажми Return. Она закроет Cliplark и удалит его вместе с данными. Строка для zsh/bash (стандартный Терминал). Приложение уйдёт в Корзину через Finder — macOS один раз спросит, разрешить ли Терминалу управлять Finder, а ещё — разрешить ли ему доступ к данным других приложений (Cliplark хранит всё в своём контейнере).

osascript -e 'if application "Cliplark" is running then tell application "Cliplark" to quit'; sleep 2; osascript -e 'tell application "Finder" to delete POSIX file "/Applications/Cliplark.app"' >/dev/null 2>&1 || echo "Перетащи Cliplark в Корзину вручную"; rm -rf ~/Library/Containers/app.cliplark.mac ~/Library/Caches/app.cliplark.mac; tccutil reset All app.cliplark.mac
