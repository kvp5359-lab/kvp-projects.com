Note Calc Бета

Заметки, которые считают сами

Пишешь как в блокноте, а строки с расчётами сразу показывают результат: переменные, валюты с курсами дня, проценты, даты и мини-таблицы.

Скачать для MacВерсия 0.5.0 · macOS 15 или новее

Бета-версия: приложение активно развивается, возможности ещё добавляются.

Что умеет

  • Переменные и ссылки на строки, слова-итоги: сумма, среднее, итого
  • Функции по-русски и по-английски, валюты, проценты, налоги, даты
  • Мини-таблицы с формулами и итогами
  • Заметки — обычные файлы Markdown в «Документах»
  • Быстрая запись из любой программы по ⌘⇧Пробел

Что нового

Версия 0.5.0 · 2026-10-12

Изменено

  • Панель оформления в новом виде, как в Google Документах: кнопки собраны в закруглённые группы, вместо букв — значки. Клик по «A» красит текст последним выбранным цветом (он виден полоской под буквой), стрелка рядом открывает палитру. При прокрутке текст плавно уходит под панель. В узком окне панель не переносится на вторую строку: кнопки, которые не поместились, прячутся под «⋯».
  • Интерфейс без тонких разделительных линий: боковая панель, вкладки, строка итогов, настройки и поля ввода отделены мягкими заливками и скруглениями.

Добавлено

  • Удалить Note Calc с Mac можно из самой программы: меню Note Calc → «Удалить Note Calc…» или Настройки → Справка. Программа уйдёт в Корзину вместе с настройками и лицензией (галочка «Оставить мои данные» их сохранит). Заметки в папке Документы → Note Calc остаются.
  • В панели оформления — подчёркивание (⌘U), цвет текста (кнопка «A», семь цветов, в тёмной теме подстраиваются), маркер (⌘⇧H) и «Очистить оформление» (⌘\): снимает с выделенного жирный, цвет, заголовок, список и остальное, ссылки остаются. Сочетания меняются в Настройках.
  • Поиск и замена внутри заметки: ⌘F, ⌘G — следующее совпадение, ⌘⇧G — предыдущее.
  • Проверка орфографии: слова с ошибками подчёркиваются, как в других программах Mac. Строки с расчётами не проверяются.
  • Курсор на ссылке показывает под ней её адрес: его можно поправить, открыть ссылку или убрать её, оставив текст.
  • Тире и кавычки при наборе: «--» с пробелом становится «—», прямые кавычки — «ёлочками» после русского текста и “такими” после английского. ⌘Z сразу после замены возвращает набранное.
  • Скобки закрываются сами: набираешь «(», появляется и «)».
  • --- на отдельной строке рисуется разделительной линией.
  • Shift+Enter в пункте списка переносит строку внутри того же пункта, а не начинает новый. Backspace в начале такой строки склеивает её обратно.
  • Оформление переносится при копировании: жирный, курсив, заголовки, списки, галочки и ссылки, вставленные из браузера, Google Документов, Word, Заметок и чатов, остаются оформленными. Скопированное из Note Calc в почту, документы и мессенджеры приходит оформленным, а туда, где оформления нет, — чистым текстом без звёздочек.

Исправлено

  • Текст в квадратных скобках больше не выглядит ссылкой и не теряет скобки.
  • Вставленный текст больше не выделяется целиком, если в нём просто встречаются числа: выделяется (и сразу считается сумма) только вставленный столбец чисел.
  • Пустые строки сохраняются при копировании в окна ввода сообщений и похожие поля, где раньше абзацы слипались.
  • Строка над --- больше не превращается в крупный заголовок.
  • Enter на пустом пункте списка выходит из списка, а не добавляет пустую строку. Backspace в начале пункта убирает значок списка (во вложенном — сдвигает пункт на уровень выше).
  • Enter посреди жирного (курсива и т. п.) слова оставляет оформленными обе половины.
  • Текст, набранный сразу после жирного слова, тоже жирный, как в Word и Google Документах. Продолжить обычным текстом — ⌘B в конце слова.
  • Нумерованный список пересчитывается, когда удаляешь, вставляешь или переносишь пункт: после удаления третьего пункта четвёртый становится третьим.
Предыдущие версии

Версия 0.4.0 · 2026-10-11

Добавлено

  • Настройки → Справка → «Лицензия»: Note Calc сейчас в бете, всё бесплатно. Там же — поле для лицензионного ключа на будущее и с какого дня ты с нами.

Изменено

  • Настройки → Справка → «Лицензия»: если сохранённый ключ больше не работает, видно почему — истёк, отозван или он для другого приложения. Там же можно убрать его, вставить новый или купить лицензию.
  • Для Note Calc теперь нужна macOS 15 или новее.

Исправлено

  • Отчёты об ошибках теперь доходят из любой страны, включая Россию: они идут через мой сервер. Включаются и выключаются, как раньше, в настройках.
  • Ссылка активации из письма открывает окно Note Calc, даже если оно было закрыто, и не заменяет уже действующий ключ: заменить его можно, вставив новый в Настройках → Справка → Лицензия.
  • В отчётах об ошибках больше не бывает имени пользователя Mac и названий заметок и файлов.

Версия 0.3.0 · 2026-10-11

Добавлено

  • Обновления сами: раз в день Note Calc проверяет новую версию и показывает, что в ней нового, а ставит только с твоего согласия. Проверить вручную — меню Note Calc → «Проверить обновления…» или Настройки → Справка; там же можно выключить автопроверку.

Изменено

  • Подсказки и тексты — на «ты», как в других моих приложениях.

Версия 0.2.0 · 2026-10-10

Добавлено

  • Окно «Что нового» после обновления, а вся история изменений — в меню Note Calc → «Что нового…» и в Настройках → Справка.
  • Отчёты об ошибках по согласию: если что-то сломалось, разработчик получит технический отчёт (версия, система, место ошибки). Твои заметки, расчёты и файлы не отправляются никогда. Включаются в Настройках → Основные; один раз программа спросит сама.

Версия 0.1.0 · 2026-10-10

Добавлено

  • Заметки, которые считают сами: пишешь как в блокноте, строки с расчётами показывают результат справа или сразу после строки.
  • Переменные и ссылки на строки: «Цена = 15», плашки-ссылки по @; переименование строки обновляет все ссылки.
  • Слова-итоги: сумма, среднее, пред, итого — считают блок над собой или всю заметку.
  • Функции по-русски и по-английски (СУММ / SUM, ОКРУГЛ / ROUND, ЕСЛИ / IF…), валюты с курсами дня, проценты и налоги, даты.
  • Мини-таблицы с формулами, итоговой строкой и столбцом, протягиванием формул.
  • Выделил строки или ячейки — внизу сумма, среднее и количество.
  • Заметки — обычные файлы Markdown в «Документах», группы — папки; вкладки, боковой список с поиском, закреплением и корзиной.
  • Картинки и файлы в заметках: вставка, перетаскивание из Finder, предпросмотр как в Finder по пробелу.
  • Быстрая запись из любой программы по горячей клавише (⌘⇧Пробел) — во «Входящие» или в выбранную заметку.
  • Значок в строке меню, окно поверх всех окон, окно у правого края экрана во всю высоту.
  • Русский и английский интерфейс, светлая и тёмная тема, масштаб, свои горячие клавиши.

Как удалить

В приложении: меню Note Calc → «Удалить Note Calc…» (или Настройки → Справка). Уберёт программу, её настройки и лицензию, доступ к папке «Документы». Заметки в Документы → Note Calc остаются — они твои.

Собираешься вернуться — поставь галочку «Оставить мои данные»: поставишь Note Calc снова, и всё будет на месте.

Эта кнопка есть с версии 0.5.0.

Вручную (для старых версий)

Открой Терминал, вставь строку и нажми Return. Она закроет Note Calc и удалит его вместе с данными. Строка для zsh/bash (стандартный Терминал). Приложение уйдёт в Корзину через Finder — macOS один раз спросит, разрешить ли Терминалу управлять Finder.

osascript -e 'quit app "Note Calc"' 2>/dev/null; sleep 2; rm -rf ~/Library/{WebKit,"Application Support",Caches,HTTPStorages,Logs}/com.kvp.notecalc ~/Library/HTTPStorages/com.kvp.notecalc.binarycookies ~/Library/Preferences/com.kvp.notecalc.plist ~/Library/"Saved Application State"/com.kvp.notecalc.savedState; defaults delete com.kvp.notecalc 2>/dev/null; tccutil reset All com.kvp.notecalc; osascript -e 'tell application "Finder" to delete POSIX file "/Applications/Note Calc.app"' >/dev/null
